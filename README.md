# AI作业生成与一键排版工具

一个面向国内文科本科生的网页端AI作业生成与一键排版工具。用户输入老师要求（主题、字数、结构、是否插图），系统自动生成偏"够交差型"的课程论文内容，支持上传图片或基于文本生成学术风格配图，自动完成目录、图注、参考文献、字体/行距/页边距排版，并导出.docx或PDF。

## 功能特点

1. **一键生成**：输入主题、字数、结构、是否需要插图，一键生成完整课程论文
2. **智能AI写作**：集成DeepSeek API，生成高质量、符合学术规范的论文内容
3. **智能排版**：自动完成目录、图注、参考文献，统一字体（宋体小四）、行距（固定值22磅）、页边距（上下2.5cm，左3cm，右2cm）
4. **图片处理**：支持上传本地图片或根据文本描述生成学术风格配图（当前版本支持上传）
5. **多格式导出**：支持导出为.docx和.pdf格式，直接可用于提交
6. **零调整**：用户全流程无需手动调整格式即可交稿
7. **故障容错**：AI服务不可用时自动降级到模板生成方式，确保服务可用性

## 技术实现

- 后端：Flask + Python
- AI写作：DeepSeek API (deepseek-chat模型)
- 文档处理：python-docx
- 前端：HTML/CSS/JavaScript
- 图片处理：Pillow（当前版本仅支持上传）

## 安装与使用

### 环境要求
- Python 3.7+
- pip包管理器

### 安装步骤

1. 克隆或下载本项目到本地
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```
   或者：
   ```bash
   python -m pip install flask python-docx openai python-dotenv
   ```

3. 配置环境变量：
   - 本地开发：创建 `.env` 文件（参考 `.env.example`）：
     ```
     DEEPSEEK_API_KEY=your_deepseek_api_key_here
     ```
   - 生产环境（如Vercel）：在平台设置中配置环境变量 `DEEPSEEK_API_KEY`

4. 运行应用：
   ```bash
   python app.py
   ```

5. 在浏览器中访问：http://localhost:5000

### 使用流程

1. 打开网页，填写论文主题
2. 设置预期字数（默认1000字）
3. 选择论文结构（三部分结构或自由结构）
4. 勾选"需要插图"（可选）
5. 如果需要插图，上传本地图片文件
6. 点击"一键生成并排版"按钮
7. 系统将自动生成论文（使用DeepSeek AI或降级到模板）并下载文件

## 文件说明

- `app.py`：后端主程序，处理用户请求、调用AI生成论文、创建文档
- `templates/index.html`：前端页面，提供用户输入表单
- `static/`：存放生成的文档和上传的图片
- `static/uploads/`：存放用户上传的图片
- `requirements.txt`：Python依赖列表
- `.env.example`：环境变量配置示例
- `vercel.json`：Vercel部署配置
- `vercel_app.py`：Vercel优化版应用入口

## 功能实现细节

### AI论文生成
- 集成DeepSeek API（deepseek-chat模型）
- 根据用户输入的主题、字数和结构生成高质量论文内容
- 支持三部分结构（引论-论点-结论）和自由结构
- 自动处理图片插入建议（当支持图片时）
- 智能后处理：确保内容完整性、结构清晰和字数适配
- 故障容错：AI服务不可用时自动降级到模板生成方式

### 文档排版
- 标题：二号黑体居中
- 正文：小四宋体，行距固定值22磅
- 段落：首行缩进两个字符，两端对齐
- 标题格式：一级标题居中，二级标题左对齐
- 页边距：上2.5cm，下2.5cm，左3cm，右2cm

### 图片处理
- 支持JPG、PNG格式
- 自动调整图片大小以适应页面宽度
- 自动生成图注："图片：[主题]示意图"
- 图片居中放置，图注居中

### 参考文献
- 自动生成格式化的参考文献列表
- 按国家标准GB/T 7714格式
- 当前版本为示例内容，实际应用中应根据论文内容生成

## 注意事项

1. 首次运行时会自动创建必要的目录结构
2. 生成的文档保存在static目录下（Vercel环境下为/tmp/uploads）
3. 上传的图片保存在static/uploads目录下（Vercel环境下为/tmp/uploads）
4. 导出的文档为.docx格式（Vercel环境下暂时不支持PDF转换）
5. 为确保中文正常显示，请确保系统已安装宋体字体
6. 第一次请求可能有较短延迟（AI API连接时间），后续请求将更快

## 已知限制

1. 图片生成功能尚未实现，当前仅支持图片上传
2. 参考文献为固定格式，实际应用中应根据论文内容智能生成
3. 不支持在线预览，仅支持文件下载
4. 未实现论文查重功能
5. 未实现多人协作功能
6. 未实现批注和导师审稿功能
7. 在Vercel等无服务器环境中，文件存储是临时的，仅用于即时下载
