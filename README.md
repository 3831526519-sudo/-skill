# AI作业生成与一键排版工具

一个面向国内文科本科生的网页端AI作业生成与一键排版工具。用户输入老师要求（主题、字数、结构、是否插图），系统自动生成偏"够交差型"的课程论文内容，支持上传图片或基于文本生成学术风格配图，自动完成目录、图注、参考文献、字体/行距/页边距排版，并导出.docx或PDF。

## 功能特点

1. **一键生成**：输入主题、字数、结构、是否需要插图，一键生成完整课程论文
2. **智能排版**：自动完成目录、图注、参考文献，统一字体（宋体小四）、行距（固定值22磅）、页边距（上下2.5cm，左3cm，右2cm）
3. **图片处理**：支持上传本地图片或根据文本描述生成学术风格配图（当前版本支持上传）
4. **多格式导出**：支持导出为.docx和.pdf格式，直接可用于提交
5. **零调整**：用户全流程无需手动调整格式即可交稿

## 技术实现

- 后端：Flask + Python
- 文档处理：python-docx + docx2pdf
- 前端：HTML/CSS/JavaScript
- 图片处理：Pillow（当前版本仅支持上传）

## 安装与使用

### 环境要求
- Python 3.7+
- pip包管理器

### 安装步骤

1. 克隆或下载本项目到本地
2. 安装依赖包：
   ```bash
   pip install flask python-docx docx2pdf
   ```
   或者使用：
   ```bash
   python -m pip install flask python-docx docx2pdf
   ```

3. 运行应用：
   ```bash
   python app.py
   ```
   或者：
   ```bash
   C:\Users\hm1\AppData\Local\Microsoft\WindowsApps\python.exe app.py
   ```

4. 在浏览器中访问：http://localhost:5000

### 使用流程

1. 打开网页，填写论文主题
2. 设置预期字数（默认1000字）
3. 选择论文结构（三部分结构或自由结构）
4. 勾选"需要插图"（可选）
5. 如果需要插图，上传本地图片文件
6. 点击"一键生成并排版"按钮
7. 系统将自动生成论文并下载PDF文件

## 文件说明

- `app.py`：后端主程序，处理用户请求、生成论文、创建文档
- `templates/index.html`：前端页面，提供用户输入表单
- `static/`：存放生成的文档和上传的图片
- `static/uploads/`：存放用户上传的图片

## 功能实现细节

### 论文生成
- 根据用户输入的主题和结构生成对应内容
- 三部分结构：引论-论点-结论
- 自由结构：简述问题-研究现状-观点-结论
- 内容目前使用模板生成，实际应用中可接入AI生成接口

### 文档排版
- 标题：二号黑体居中
- 正文：小四宋体，行距固定值22磅
- 段落：首行缩进两个字符，两端对齐
- 标题格式：一级标题居中，二级标题左对齐
- 页边距：上2.5cm，下2.5cm，左3cm，右2cm

### 图片处理
- 支持JPG、PNG格式
- 自动调整图片大小以适应页面宽度
- 自动生成图注："图片：[主题]示意图"
- 图片居中放置，图注居中

### 参考文献
- 自动生成格式化的参考文献列表
- 按国家标准GB/T 7714格式
- 当前版本为示例内容，实际应用中应根据论文内容生成

## 注意事项

1. 首次运行时会自动创建必要的目录结构
2. 生成的文档保存在static目录下
3. 上传的图片保存在static/uploads目录下
4. 导出的PDF文件会与docx文件同名，仅后缀不同
5. 为确保中文正常显示，请确保系统已安装宋体字体

## 已知限制

1. 当前版本的论文内容生成较为简单，实际应用中应集成更先进的AI生成模型
2. 图片生成功能尚未实现，当前仅支持图片上传
3. 参考文献为固定格式，实际应用中应根据论文内容智能生成
4. 不支持在线预览，仅支持文件下载
5. 未实现论文查重功能
6. 未实现多人协作功能
7. 未实现批注和导师审稿功能
